Entity resolution

One district, four spellings

Every source row is matched to a canonical district before any number is compared. Renamed districts use a rename rule, spelling variants use string similarity, and each match keeps its method and score so it can be audited.

Computed, then explained

Findings with their evidence

Each finding is produced by a stated rule over the joined data. Open any one to see the rule, the data points, and the source row each came from.

Query across schemes

Ask a question in plain words

The question is turned into a structured query over the joined district table. The query is shown, so you can check what was actually asked of the data.

The question is parsed on the server by a rule-based parser for a fixed set of metrics, and the SQL shown is the statement that ran on the database. The production design replaces the parser with an LLM that writes SQL against the same table.

About

Samanvay joins scheme data published by different ministries onto one resolved district record, then computes gaps, overlaps and anomalies with their evidence.

Data sources

Jal Jeevan Mission (Lok Sabha Q.1425), PMAY-Gramin (Lok Sabha Q.2078), NFHS-5 district fact sheets, Census 2011 boundaries with LGD codes.
